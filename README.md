# Курсовой проект: База данных "Проекты GitHub"

Файловая база данных – это файл, в котором хранятся упорядоченные записи данных, описывающих заданную предметную область. Для работы с ними необходимо реализовать программу, позволяющую создавать новые записи, выполнять поиск по заданным критериям.

Целью данной работы является разработка программы для реализации файловой базы данных с заданным набором функций.

Для достижения поставленной цели, необходимо решить следующие задачи:

1. Реализовать структуру данных и определить подходящие типы данных для каждого поля.

2. Реализовать простой и понятный интерфейс для взаимодействия пользователя с программой, который будет работать пока пользователь не захочет выйти из программы.

3. Реализовать сохранение данных в бинарный файл и загрузку данных из бинарного файла.

4. Реализовать поиск записей по названию проекта.

5. Реализовать поиск записей в заданном интервале значений (по количеству проблем).

6. Реализовать сортировку записей по количеству звёзд.

## Поля структуры github_project

1. `char name[50]` - название проекта

2. `char description[150]` - описание проекта (кириллица занимает 2 байта на символ)

3. `char language[30]` - язык программирования

4. `int stars` - количество звёзд

5. `int forks` - количество форков

6. `int issues` - количество проблем (issues)

## Выполняемые программой операции

1. Загрузка данных из файла – загрузка базы данных проектов из бинарного файла, имя которого вводит пользователь.
2. Просмотр всех записей – вывод всей базы данных проектов на экран.
3. Поиск по названию проекта – поиск проектов по точному совпадению названия.
4. Поиск по диапазону количества проблем – поиск проектов, у которых количество issues лежит в заданном пользователем диапазоне.
5. Сортировка данных – сортировка всей базы данных по количеству звёзд по убыванию.
6. Добавление новой записи – ввод информации о новом проекте с клавиатуры.
7. Сохранение данных в файл – сохранение имеющихся данных в бинарный файл, имя которого вводит пользователь.
8. Заполнение случайными данными – добавление записей со случайными значениями.
9. Выход – завершение работы программы.

## Описание функций программы

1. `int show_menu()`

   Назначение: Отображает текстовое меню с доступными действиями и получает выбор пользователя.

   Возвращает: Целое число (int), соответствующее выбранному пункту меню (от 1 до 9).

2. `github_project input_data()`

   Назначение: Интерактивно запрашивает у пользователя данные для заполнения одной записи.

   Возвращает: Заполненную структуру github_project с данными, введёнными пользователем.

3. `void output_data(github_project project)`

   Назначение: Выводит на экран все поля записи.

   Параметры:

   - project - структура github_project, данные которой нужно отобразить.

4. `int load_from_file(const char* filename, github_project* projects)`

   Назначение: Загружает массив записей из бинарного файла в память (не более MAX записей).

   Параметры:

   - filename - имя файла.
   - projects - указатель на массив структур github_project.

   Возвращает: количество успешно загруженных записей или -1, если файл не удалось открыть.

5. `void view_all_records(github_project* projects, int count)`

   Назначение: Отображает все записи, находящиеся в оперативной памяти.

   Параметры:

   - projects - указатель на массив структур github_project.
   - count - количество актуальных записей в массиве.

6. `int search_by_name(const github_project* projects, int count, const char* query, int* found_indexes)`

   Назначение: Осуществляет поиск записей, название которых полностью совпадает с введённым (используется `strcmp`).

   Параметры:

   - projects - указатель на массив структур github_project.
   - count - количество записей в массиве.
   - query - искомое название проекта.
   - found_indexes - массив для индексов найденных записей.

   Возвращает: количество найденных записей или -1 в случае некорректных параметров.

7. `int search_by_issues_range(const github_project* projects, int count, int min, int max, int* found_indexes)`

   Назначение: Осуществляет поиск записей, у которых значение поля issues попадает в диапазон [min, max] (границы включаются).

   Параметры:

   - projects - указатель на массив структур github_project.
   - count - количество записей в массиве.
   - min - нижняя граница диапазона.
   - max - верхняя граница диапазона.
   - found_indexes - массив для индексов найденных записей.

   Возвращает: количество найденных записей или -1 в случае некорректных параметров (в том числе если min > max).

8. `int compare(const void* a, const void* b)`

   Назначение: Функция сравнения для `qsort`. Сравнивает две записи по количеству звёзд (по убыванию).

   Параметры:

   - a, b - указатели `const void*` на сравниваемые элементы массива.

9. `void sort_data(github_project* projects, int count)`

   Назначение: Сортирует массив записей по убыванию количества звёзд, используя стандартную функцию `qsort` и функцию сравнения `compare`.

   Параметры:

   - projects - указатель на массив структур github_project.
   - count - количество актуальных записей в массиве.

10. `int add_new_record(github_project* projects, int count)`

    Назначение: Добавляет одну новую запись в массив. Данные для записи запрашиваются у пользователя через функцию `input_data`. Если достигнут лимит MAX (100), запись не добавляется.

    Параметры:

    - projects - указатель на массив структур github_project.
    - count - текущее количество актуальных записей в массиве.

    Возвращает: новое количество записей в массиве после добавления.

11. `int save_to_file(const char* filename, const github_project* projects, int count)`

    Назначение: Сохраняет все текущие записи из оперативной памяти в бинарный файл.

    Параметры:

    - filename - имя файла.
    - projects - указатель на массив структур github_project.
    - count - количество записей, которые необходимо сохранить.

    Возвращает: количество сохранённых записей или -1, если файл не удалось создать.

12. `int getRandomNumber(int min, int max)`

    Назначение: Возвращает случайное целое число из диапазона [min, max].

13. `int generate_random_data(github_project* projects, int count)`

    Назначение: Генерирует указанное пользователем количество записей со случайными данными (название, описание и язык выбираются из заготовленных списков; звёзды – от 100 до 250000, форки – от 10 до 80000, issues – от 0 до 3000) и добавляет их в массив.

    Параметры:

    - projects - указатель на массив структур github_project.
    - count - текущее количество актуальных записей в массиве.

    Возвращает: новое количество записей в массиве после добавления сгенерированных.
